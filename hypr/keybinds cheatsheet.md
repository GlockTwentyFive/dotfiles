SUPER + Q => Terminal (Kitty)
SUPER + SPACE => App Launcher
SUPER + W => Wallpapers
SUPER + E => Emoji
SUPER + V => Clipboard

SUPER + C => Close App
SUPER + P => Kill Hyprland Session

SUPER + M => Toggle Float

SUPER + S => Special Workspace

SUPER + L => Lock Screen

SUPER + PrintScreen => Selected area screenshot
PrintScreen => Saves a shot of the whole screen
- Screenshots are saved in ~/Pictures/Screenshots directory and will be copied to clipboard as well using wl-clipboard.
